## 🚀 خطوات النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم `bi-design`.
2. ارفع محتويات هذه الحزمة (`index.html`, `assets/`, `README.md`, `robots.txt`, `sitemap.xml`, `.nojekyll`) إلى الفرع الرئيسي `main`.
3. ادخل إلى **Settings** → **Pages** واختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. سيعمل موقعك خلال ثوانٍ على الرابط: `https://<username>.github.io/bi-design/`.
